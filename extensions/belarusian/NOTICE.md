# Notices

The Belarusian dictionary data is generated from Hunspell source files `be-BY.aff` and `be-BY.dic` obtained from the [National Corpus of the Belarusian Language spell checker](https://bnkorpus.info/spell.html).

The local Hunspell source files in this checkout do not include embedded license metadata. Verify the dictionary redistribution terms before publishing this extension.
